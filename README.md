# IndoorTwin Dissertation Evidence

Supporting data, saved plots and evaluation notebooks for **Digital Twin-Enabled Edge-IoT: Towards Indoor Environmental and Safety-Awareness Monitoring**.

**Aung Min Naing · Auckland University of Technology · 2026**

This repository provides supporting evidence for dissertation markers and examiners. Only the selected collected data and evaluations used in the dissertation are included.

## Evidence guide

| Executed notebook | Evidence |
| --- | --- |
| [01 — Power interruption](notebooks/01_rq1_power_interruption.ipynb) | Six node power-interruption tests |
| [02 — Telemetry interruption](notebooks/02_rq1_telemetry_interruption.ipynb) | Eighteen interruption cycles |
| [03 — State checks](notebooks/03_rq2_state_checks.ipynb) | Synthetic and physical state checks |
| [04 — States and timeline](notebooks/04_rq2_integrated_timeline.ipynb) | Controlled actions and the seven-phase room record |
| [05 — CO₂ simulation](notebooks/05_rq3_co2_simulation.ipynb) | Measured records and model evaluation |
| [06 — Anomaly detection](notebooks/06_rq3_anomaly_detection.ipynb) | Recorded data and altered-replay evaluations |
| [07 — Command and response](notebooks/07_rq4_command_response.ipynb) | Fan commands, acknowledgements and measured responses |

## Reviewing the evidence

**Open the notebooks to see saved results and plots; no rerun is required.** Standalone copies are available in [plots](evidence/plots/) and [evaluation tables](evidence/tables/).

- [Collected data and configurations](data/): original filenames and experiment IDs are preserved.
- [Data and evaluation notes](DATA_NOTES.md): record scope, units, interpretation and optional regeneration.

The repository includes seven executed notebooks, 18 evaluated plots and 24 evaluation tables. Supporting calculation code is in `src/`. No rerun is required to review the evidence.
